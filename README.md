# Security Log Investigation

## Project Overview

This repository contains the investigation notebook, log normalization script, detection rules, and final incident report for the **Security Log Investigation** task.

The project focuses on analyzing authentication logs, identifying suspicious login activities, and detecting potential brute-force and password-spraying attacks.

## Project Objectives

- Analyze authentication event logs.
- Parse and normalize raw security log data.
- Identify suspicious authentication activities.
- Detect brute-force attack patterns.
- Detect potential password-spraying attempts.
- Document investigation findings.
- Provide security recommendations and remediation steps.
